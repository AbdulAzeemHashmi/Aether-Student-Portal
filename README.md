# AETHER: Zenith Academic OS 🌌✨

Welcome to the finalized AETHER platform. This application is a premium "Learning OS" designed with high-fidelity glassmorphism aesthetics and a robust MongoDB-driven architecture.

## 🚀 How to Run the Application

Follow these steps to get the system up and running:

### 1. Database Setup (Cloud)
AETHER uses **MongoDB Atlas** for data storage. The application is already configured to connect to the cloud database.
*   *Note: Ensure your internet connection is active for the cloud database uplink.*

### 2. Python Environment Setup
1. Open your terminal/command prompt in the project folder.
2. Install the required libraries using pip:
   ```bash
   pip install -r requirements.txt
   ```

### 3. Launching the App
1. Run the backend server:
   ```bash
   python app.py
   ```
2. You should see a message: `Checking Database Integrity... Database Ready.` and `Running on http://0.0.0.0:3000`.

### 4. Accessing the Platform
1. **On PC:** Open your browser and go to: **[http://localhost:3000](http://localhost:3000)**
2. **On Mobile:** Connect your phone to the same WiFi and go to: `http://<your-pc-ip>:3000`
3. **Login:** Use your registered Roll Number or create a new account via **Join AETHER**.

## 🛠 Features
- **Animus Hub**: Central mission control with a sleek glassmorphism grid.
- **Nexus Map**: An interactive "Skill Tree" graph representing degree prerequisite topology.
- **Academic Chronicle**: A temporal visualization (timeline) of your entire academic odyssey.
- **Intelligence Report**: AI-driven analysis of your GPA, health scores, and gatekeeper courses.
- **Neural Identity**: Persistent profile synchronization across all your devices.
